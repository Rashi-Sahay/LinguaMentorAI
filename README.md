LinguaMentorAI

LinguaMentorAI is an AI-powered language learning assistant designed to help users practice languages through interactive conversations.

Features
Conversational language practice
Real-time grammar and vocabulary corrections
Interactive roleplay scenarios
Vocabulary learning and review
Personalized language practice
Simple and user-friendly interface
Tech Stack

Frontend: React and Vite
Backend: Python and FastAPI
AI: Large Language Model integration
